# Java Inheritance Examples

This repository contains simple and well-structured Java programs demonstrating various inheritance types in Object-Oriented Programming (OOP).

## 📂 Contents
- **singleInheritanceWithMethod.java** – Basic single inheritance using methods.
- **singleInheritancewithConstructor.java** – Single inheritance with constructors.
- **multilevelInheritance.java** – Demonstrates multilevel inheritance chain.
- **Hierarchical.java** – Shows hierarchical inheritance with multiple subclasses.
- **multipleInheritance.java** – Example of multiple inheritance using interfaces.
- **hybridInheritance.java** – Combines class and interface inheritance (hybrid model).

## 💡 Concepts Covered
- Parent–child relationships in classes
- Method overriding and constructor chaining
- Interface implementation and default methods
- Hybrid inheritance combining classes and interfaces
